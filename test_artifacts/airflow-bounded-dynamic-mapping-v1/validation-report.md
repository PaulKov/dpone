## Public contract and compatibility

- `airflow.mapping.mode` defaults to `internal`; existing manifests and packs do
  not opt into Airflow task mapping.
- `visible` maps one chunk per task and fails when it exceeds `max_items`.
  `summary` creates deterministic contiguous ranges, never more than 200 items.
- Mapped plans own the Airflow pool and `max_active_tis_per_dag`; operator
  overrides cannot weaken these limits.
- Runtime accepts only a bounded index-range item, re-plans canonical chunks and
  compares the backfill plan hash before source or sink I/O. Predicate SQL never
  comes from the environment.
- The dpone ledger remains authoritative. PostgreSQL and MSSQL audit-state
  stores provide initialization locks, per-chunk leases and owner compare-and-set
  completion; local-file and ClickHouse state fail closed for mapped execution.
- Generated mapped packs use `mapped_kpo_kwargs`. The current provider validates
  the mapping plan before normalizing it; older providers fail their existing
  required-`kpo_kwargs` validation instead of running the whole campaign.
- Mapping payloads are additive to pack/XCom schemas and contain no credentials,
  predicates or row data.

## Documentation and CJM impact

The five-command beginner path is unchanged because `internal` remains the
default. The self-service guide now shows when to choose `visible` or `summary`,
the task and concurrency limits, supported state backends and diagnostic error
codes. Provider and backfill guides explain the static plan, inline outcome
gate, retry behavior and ledger ownership.

## Review findings and remaining risk

The integrator review found one release-blocking fail-closed defect: mapped
context was inspected only after the non-chunked fast path. A drifted process
could therefore execute as a whole. The guard now runs before that path and a
regression test proves that no process call occurs.

Remaining risks:

- Distributed behavior is covered by deterministic store/connector tests, but
  multi-pod PostgreSQL/MSSQL evidence remains UNVERIFIED.
- Chunk leases are finite. Operators must size `lease_ttl_minutes` above the
  maximum expected chunk duration and use an idempotent supported backfill inner
  mode; production lease-renewal certification remains a follow-up operational
  hardening concern.
- Fresh independent agent review remains unavailable. Keep the pull request
  draft until CI and maintainer review complete.

The implementation is ready for maintainer review and integration. It is not
yet a live multi-pod production certification claim.
