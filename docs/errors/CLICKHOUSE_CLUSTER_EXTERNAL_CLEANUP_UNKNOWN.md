# CLICKHOUSE_CLUSTER_EXTERNAL_CLEANUP_UNKNOWN

The desired generation may be committed, but the runtime cannot prove exact
predecessor removal on every required member. Queue evidence, inventory, or an
object identity is unavailable or contradictory.

Keep every unresolved predecessor. Restore complete read-only evidence and
retry the same operation so dpone can reconcile the bound cleanup entry and
exact UUIDs.

Do not drop objects by name, prefix, age, or row count. Follow
[Cleanup unknown](../clickhouse-cluster-publication-runbook.md#cleanup-unknown).
