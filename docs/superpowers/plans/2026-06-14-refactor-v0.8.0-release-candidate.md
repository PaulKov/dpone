# Refactor V0.8.0 Release Candidate Implementation Plan

> **Historical design record.** Commands below are preserved as implementation evidence and are not current runbooks. Use [Module-size debt ratchet](../../module-size-ratchet.md) for the supported exact-SHA command.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Promote the local runtime/source-sink/CDC/route-readiness refactor into a clean `v0.8.0` release candidate without mixing already released benchmark artifacts or unrelated local evidence files.

**Architecture:** Build a fresh RC branch from `origin/master` at `v0.7.10`, transfer only framework/runtime/refactor changes, and validate the release through explicit CLI, Python API, nested-object, source-to-sink, contract, docs, CI, and packaging gates. Keep generated or local-only benchmark/test artifacts outside the release unless a documented contract test requires them.

**Tech Stack:** Python 3.11/3.12, uv, pytest, ruff, mypy, MkDocs Material, GitHub Actions, PyPI release workflow.
